# Operator Brief: Jerry

Jerry gets a local, deterministic pressure test around jerry, hardest, and unsolved. The useful part is not the dashboard; it is the repeatable evidence path from fixture to failure to operator action.

## Highest-leverage checks

- jerry evidence replay -> block release until cited evidence is regenerated (jerry_coverage, evidence ev_0000).
- problem operator packet -> accept only if decision claims cite fixture evidence (hardest_risk, evidence ev_0055).
- unsolved regression harness -> open a regression issue with trace and benchmark delta (unsolved_precision, evidence ev_0022).
- hardest boundary probe -> route to reviewer with evidence packet (problem_latency, evidence ev_0121).

## What makes this useful

The workflow is intentionally local and deterministic. A reviewer can run the same fixture set, inspect the evidence IDs, open the dashboard, and see exactly why a recommendation passed, went to review, or blocked.
